# Arduino Obstacle Avoiding Robot 🚗

## Description
An autonomous robot car designed to detect and avoid obstacles using an ultrasonic sensor.

## Components
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- L298N Motor Driver
- 2 DC Motors
- 2WD Robot Chassis

## Working Principle
The ultrasonic sensor measures the distance between the robot and nearby obstacles.

When an obstacle is detected, the robot stops, changes direction and continues moving.
